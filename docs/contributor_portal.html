Backend implementation guide for HRL

HRL is a fully graphics‑API‑agnostic engine.
All GPU logic lives exclusively inside the backend through a strict RHI contract. The HRL core never includes or exposes native APIs such as OpenGL, Vulkan, DirectX or Metal.

As a backend contributor, you are expected to implement every RHI function. Missing or partially implemented functions result in an invalid backend.

⚠️ The backend is responsible for most of the engine behavior: resource lifetime, GPU state, pipelines, framebuffers and synchronization.

Initialization RHI

void RHI_Init()

Initializes global backend state and loads the graphics API.

void RHI_InitContext( HRL_uint width, HRL_uint height, void* loader)

Initializes the rendering context and swapchain‑dependent resources.

void RHI_Shutdown()

Releases all backend resources and shuts down the graphics API.

Frame Flow Frame

void RHI_BeginFrame()

Marks the beginning of a new GPU frame.

void RHI_ResetFramebuffer()

Resets framebuffer bindings to a known default state.

Viewport & Camera View

void RHI_BindViewport( HRL_Viewport* viewport)

Binds the active viewport and camera. Must be called before any draw calls.

void RHI_ComputeFrameMatrices()

Computes per‑frame camera and projection matrices.

Materials & Draw Draw

void RHI_BindMaterial( HRL_Material* material)

Binds shaders, textures and GPU states for the material.

void RHI_DrawMesh( HRL_Mesh* mesh)

Issues the actual GPU draw call.

Lights Lighting

void RHI_UpdateLights(lights)

Uploads and updates light data for the current frame.
